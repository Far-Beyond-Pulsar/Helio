# path count reason
# Paths are relative to helio/crates. State that must be one per process is in
# helio_core::runtime::Shared, never here.
helio-core/src/runtime.rs 1 the one pointer to the host's Shared state, set by attach
helio-core/src/graph/scheduling.rs 1 interned pass-chain labels, bounded to 256: equal names compare equal in every copy; a known, bounded leak per copy
helio-core/src/profiling/mod.rs 1 profiler instance ids: collide only across copies that each build a profiler, and a plugin never builds one (the render_runtimes service owns renderers)
helio-core/src/shader/hot.rs 2 environment switches read once (enabled, from-disk): the same answer in every copy
helio-frame-api/src/lib.rs 2 interned name lists and names ('static str caches): equal names compare equal in every copy; a known, bounded leak per copy
helio-graph-asset/src/resources.rs 2 interned resource names: equal names compare equal in every copy; a known, bounded leak per copy
helio-presets/src/presets.rs 2 the base node registry made once and a warn-once list: a library's graphs are built by the host from its registrations, so a second registry is never consulted
helio-settings/src/lib.rs 2 read-only tables of constants
helio-tasks/src/lib.rs 1 the task host, which the host installs into each copy through runtime::attach
passes/3d/helio-pass-buffer-view/src/lib.rs 1 a read-only table of constants
passes/3d/helio-pass-reference/src/lib.rs 2 read-only tables of constants
scenedb-inspector-agent/src/lib.rs 1 the debug inspector's bridge: started by the host (engine_backend) only, never by a plugin library
