# Photographic stone material integration

The cathedral structural stone batch now uses the CC0 Castle Wall Variation diffuse, OpenGL normal and packed AO/roughness/metal maps by Rob Tuytel / Poly Haven. Source: https://polyhaven.com/a/castle_wall_varriation ; license: https://polyhaven.com/license . Original PNGs, download URLs, MD5 and SHA256 hashes are tracked under crates/examples/assets/castle_wall_varriation. All three downloads match the API MD5. Assets are embedded; no absolute filesystem path or network is needed at runtime.

Dominant-plane UVs use the stated two-metre tile width and a matching tangent basis. The renderer exposes an explicit shared material sampler setter that increments the descriptor version. Architectural examples select repeat, trilinear filtering and 8x anisotropy without changing other renderer users' default sampler. SceneDB retains texture ownership. All mip levels are uploaded: color averages in linear light before sRGB encoding, normal/ARM channels average linearly. The material shader normalizes sampled normals. These are normal maps, not displacement, and do not alter RT geometry or provide microgeometry self-shadowing.

Interactive cathedral and drone scene setup share the material loader with offscreen capture. Both release binaries build. Native interaction was not tested. The checker diagnostic takes precedence. HLFS_NO_STONE_TEXTURES=1 restores flat materials; HLFS_NO_STONE_NORMALS=1 retains color/ARM but disables normal mapping. Untextured control frame 99 exactly matches the preceding key-support candidate capture. Normal mapping changes 877775 RGB pixels versus the no-normal control at frame 99 (mean absolute RGB-channel difference 0.463 on the 0-255 scale), confirming the flag/binding path is active; this is not a reference-normal accuracy proof.

All four serial captures use RT presampling, FXAA, colored glass, fixed 60 Hz moving camera, 100 frames, and exclude the first 16 warmup frames from the HLFS GPU statistics. 1440p is native output/internal resolution, with 1280x720 HLFS samples. 4K is native output/internal resolution with 1920x1080 samples and SSR enabled. See results.json and raw CSV for exact medians/p95. GPU measurements cover HLFS only, excluding texture loading, AA, SSR, TLAS and the rest of the frame. Source image decoding/mip generation happens once before rendering.

Inspected frame 99 with normals on/off at 1440p and with SSR at 4K. Stone detail is visible on the structural walls; colored transmission and reflections remain. Known jagged shadow edges, flat/faceted mouldings, mismatched detail between textured walls and untextured stonework, and incomplete reflection coverage remain. No artifact-free, temporal-shimmer, physically complete glass, or 3-4 ms acceptance is claimed. This is an incremental material integration, not the requested final cathedral reconstruction.
